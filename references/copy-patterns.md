# 文案写法指令库

`sample_variant.py` 抽到哪个值，就按对应小节写。**同一篇里各维度要协同**：视角、钩子、结构、语气必须自洽（例：`场景对话` + `冷静分析` 会别扭，此时优先服从 `perspective`）。

---

## 1. perspective 叙事视角

| 取值 | 人称 | 写法指令 | 开头示例 |
|---|---|---|---|
| 备考者自述 | 我 | 以"正在准备的人"身份讲发现，允许写困惑、踩坑、恍然大悟。**不假装上岸** | 我对着职位表看了一晚上，才反应过来一个问题 |
| 过来人复盘 | 我/我们 | 已考过的人回看，讲"当时要是知道"。口吻平视，不说教 | 去年这个时候我也在纠结，现在回头看，最该先搞清的是 |
| 数据观察者 | 无主语/我们 | 第三方摆数据，句子短、结论稳，不煽情 | 把今年的招录数据摊开看，有几个变化挺明显 |
| 老师答疑 | 你/大家 | 回答高频疑问，先复述问题再拆解。**禁止**"私信我""来问我" | 最近问得最多的一个问题：我这个专业到底能不能报 |
| 清单罗列 | 无 | 几乎不出现"我"，直接上条目，每条一个信息点 | 先把结论放前面，一共 6 条 |
| 场景对话 | 你/我 | 用 2-4 轮对话推进，把信息藏进问答里 | "我这个情况还能报吗？"——先别急，看这三个条件 |

## 2. hook 开头钩子（正文前 1-2 句）

| 取值 | 模板 | 示例 |
|---|---|---|
| 反常识 | 很多人以为 X，其实 Y | 很多人以为岗位越多越好报，其实恰恰相反 |
| 数字冲击 | 直接甩一个反差最大的数字 | 4652 个人抢 1 个岗，这不是段子 |
| 痛点共鸣 | 描述一个具体处境 | 专业一栏翻来覆去找不到自己的，先别关页面 |
| 时间紧迫 | 用临近节点起手 | 报名通道开了，真正容易出错的是后面几步 |
| 结论前置 | 第一句就给答案 | 先说结论：能报的岗位比你想的多 |
| 提问 | 提一个用户会自问的问题 | 同一个岗位，为什么有人能报有人不能？ |
| 对比 | A 和 B 摆一起 | 国考 98 个人抢一个岗，省考 59 个，差在哪 |

**禁止**：7 种钩子不能在同一素材的相邻两版里重复（去重脚本已保证，人工复核时再确认一次）。

## 3. structure 结构骨架

**总分总**
```
开头：结论一句话
主体：3-4 段，每段一个支撑点，段首小标题
结尾：回到结论 + 一句行动建议
```

**时间线**
```
按"报名前 → 报名中 → 报名后"或"公告 → 笔试 → 面试"推进
每个节点写：时间 + 要做什么 + 容易错的地方
```

**问题-解答**
```
连续 3-5 个真实疑问，每个：问句（加粗）→ 2-4 句答
最后补一个"还有人问"
```

**清单体**
```
编号 1-6，每条 1-3 行，信息密度高
条目之间不写过渡句
```

**对比拆解**
```
先立对比轴（国考 vs 省考 / A 岗 vs B 岗 / 今年 vs 去年）
逐项对照，最后给判断
```

**步骤流**
```
第 1 步 → 第 2 步 → 第 3 步
每步：做什么 + 判断标准 + 卡住了怎么办
```

## 4. tone 语气

| 取值 | 句长 | 特征 | 避免 |
|---|---|---|---|
| 姐妹口语 | 短 | "真的""其实""别慌""咱"；可用 1-2 个 emoji 分区 | 过度撒娇、颜文字 |
| 冷静分析 | 中 | 少形容词，多"从数据看""这意味着" | "震惊""炸了" |
| 干货直给 | 短 | 一句一个信息点，几乎无过渡 | 铺垫超过 2 句 |
| 温和陪伴 | 中 | "慢慢来""不用急""很多人都会" | 贩卖焦虑 |
| 犀利提醒 | 短 | 直接指出误区，但不攻击人 | 羞辱性表达、绝对化结论 |

---

## 5. rhythm 段落节奏

- **短句密排**：每段 1-2 句，句均 ≤18 字，段间空一行
- **长段+小标题**：每段 3-5 句，配 2-4 个加粗小标题
- **编号列表**：`1.` `2.` `3.` 开头，每条独立成段
- **引号对话**：`"……"` 与叙述交替，2-4 轮

---

## 6. title_pattern 标题公式（≤20 字）

| 取值 | 公式 | 示例 |
|---|---|---|
| 数字型 | 数字 + 对象 + 结论 | 21 个地市竞争比，深圳断层第一 |
| 疑问型 | 疑问词 + 痛点 | 专业不对口，真的没岗可报吗 |
| 对比型 | A vs B + 差异点 | 国考 98:1，省考 59:1，差在哪 |
| 结论型 | 直接给判断 | 今年选岗，先看这一条就够 |
| 身份型 | 人群标签 + 提醒 | 应届生注意，这三个时间点别记错 |
| 紧迫型 | 时间/动作 + 后果 | 报名只剩 3 天，这步别拖到最后 |

**标题禁忌**：不用"必看""速看""震惊""内部"；不用书名号堆砌；不写"第 X 期"。

## 7. 同义表达库（换说法不换事实）

| 原词 | 可替换 |
|---|---|
| 招录 | 招聘 / 放出岗位 / 计划招收 |
| 竞争比 | 报录比 / 多少人抢一个岗 / 录取难度 |
| 报考条件 | 门槛 / 报名要求 / 资格条件 |
| 笔试时间 | 考试时间 / 笔试安排在 |
| 应届毕业生 | 应届生 / 当年毕业的 |
| 基层工作经历 | 基层经历 / 在基层干过 |
| 专业不限 | 不限专业 / 什么专业都能报 |
| 扩招 / 缩招 | 岗位变多 / 名额减少 |

> 数字、专有名词、政策名称**不替换**（"三支一扶"不能写成"支教"）。

---

## 8. 去 AI 味替换

| AI 味 | 改成人话 |
|---|---|
| 首先 / 其次 / 最后 | 直接分点，或"先说…""还有一个…" |
| 综上所述 | 所以 / 说到底 |
| 值得注意的是 | 有个细节 / 这里容易忽略 |
| 对于…而言 | 对…来说 |
| 具有重要意义 | 直接影响你能不能报 |
| 随着…的不断发展 | 删掉，直接说事 |
| 旨在 / 致力于 | 就是想 / 主要是 |

**每篇自检**：读一遍，如果每段开头都是"此外""同时""因此"，重写。

---

## 9. 标签（8-10 个）

组合规则：2 个大词（#公务员考试 #考公）+ 2 个项目词（#国考 #广东省考）+ 2 个地域词（#广东考公 #广州考公）+ 2-3 个长尾（#选岗 #应届生考公）。

不堆无关标签，不写"#热门""#推荐"这类泛词。

---

## 10. NG 清单

- ❌ 出现"上岸""包过""押题""内部消息"（广告法 + 平台风险）
- ❌ 编造"某考生说""有同学反馈"当事实
- ❌ 把"预计/参考"写成"确定/官方公布"
- ❌ 结尾引流："评论区扣 1""主页领取""私信我"
- ❌ 大段复制素材原文（连续 20 字以上重合即算搬运）
