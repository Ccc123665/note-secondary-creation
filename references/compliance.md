# 合规规则与词库

合规是**一票否决**，不是"尽量"。命中 BLOCK 级，改到不命中才能交付。

## 一、分级

| 级别 | 含义 | 处理 |
|---|---|---|
| `BLOCK` | 违法/违规/平台必删 | 必须改，脚本 exit 1 |
| `WARN` | 有风险，需人工判断 | 可放行，但要在质检报告里写明理由 |

---

## 二、BLOCK 级

### 1. 引流信息（最高危）

| 类型 | 正则/关键词 |
|---|---|
| 网址 | `https?://`、`www\.`、`\.com`、`\.cn`、`\.net`、`\.org` |
| 手机号 | `1[3-9]\d{9}` |
| 社交号 | `微信`、`VX`、`vx`、`威信`、`QQ`、`扣扣`、`加我`、`私信`、`戳我`、`滴滴我` |
| 二维码 | `二维码`、`扫码`、`扫一扫`、`长按识别` |
| 导流动作 | `主页`、`评论区`、`领取`、`免费领`、`回复.{0,4}领`、`点击链接`、`阅读原文`、`关注我`、`点赞收藏` |
| 变体 | `㈱`、`薇`、`V：`、`＋V`、`扣 1` |

> 图片一律不画二维码、不写任何联系方式。

### 2. 其他机构名

直接命中：`华图`、`粉笔`、`腰果`、`纵横`、`导氮`、`京佳`、`上岸鸭`、`格燃`、`步知`、`大树教育`、`优路`、`中公以外的 XX 公考`

泛匹配：`[\u4e00-\u9fa5A-Za-z]{2,6}教育` / `[\u4e00-\u9fa5]{2,6}公考`
白名单（不算违规）：`中公教育`、`教育局`、`教育部`、`教育考试院`、`教育部门`、`教育阶段`、`教育类`、`学历教育`

> 素材若来自其他机构（白皮书/讲义截图），**必须重排版**，不得保留对方 logo、页眉、水印、页脚。

### 3. 广告法 / 培训行业禁语

`保过`、`包过`、`必过`、`保分`、`保录`、`押题`、`命中`、`内部资料`、`绝密`、`泄题`、`原题`、`官方指定`、`命题组`、`100%`、`百分百`、`协议班`、`包就业`、`保上岸`

> 内部规范补充：**"资料"一律写"课件"**，**"真题"写"历年试题"**，**"上岸"写"成功入围/考入"**。

### 4. AI 生成标识

`AI 生成`、`AI生成`、`AI 创作`、`由 AI`、`人工智能生成`、`AIGC`、`ChatGPT`、`大模型生成`、`本文由 AI`、`AI 辅助创作`

> 文案不写，图片不加任何 "AI generated" 水印。

## 三、WARN 级（人工判断）

| 词 | 风险 | 建议 |
|---|---|---|
| 最好 / 最佳 / 最强 / 最优 / 最高级 | 极限词 | 换成"更合适/比较稳" |
| 第一 / 排名第一 | 极限词（客观数据排名可酌情） | 数据排名可保留，但写"居首/最高"更稳 |
| 唯一 | 绝对化 | 换"少数几个" |
| 顶级 / 国家级 / 世界级 | 无依据背书 | 删掉 |
| 绝对 / 一定 / 肯定 | 绝对化承诺 | 换"通常/大概率" |
| 独家 / 首发 / 史上 / 前所未有 | 无法证实 | 删掉 |
| 秒杀 / 疯抢 / 最后 X 个 | 促销诱导 | 删掉 |

> WARN 命中不阻断，但质检报告必须逐条列出并给处理结论。

## 四、替换对照表

| 原表述 | 合规替换 |
|---|---|
| 资料 | 课件 |
| 真题 | 历年试题 |
| 押题 | 冲刺卷 / 模拟卷 |
| 上岸 | 成功入围 / 考入 |
| 保过班 | 系统班（不承诺结果） |
| 内部消息 | 公开信息 / 官方公告 |
| 最全 / 最新 | 较全 / 已更新 |
| 第一名 | 居首 / 排在前面 |

## 五、图片合规（渲染层强制）

| 项 | 规则 | 实现 |
|---|---|---|
| 中公 logo | **每张图必须有**，高 44px，距边 40px | `render_note.py` 强制绘制，无开关 |
| 二维码 | 任何版式都不画 | 代码层无该能力 |
| 联系方式 | 不出现手机号/微信/网址 | 内容来自 content.json，闸门 2 复查 |
| 其他机构水印 | 不得出现 | 素材图若含对方标识，裁切或不用 |
| AI 水印 | 不加 | — |
| 敏感图形 | 不用政治/宗教/地图争议元素 | 只用几何图形与小鹿 |

---

## 六、素材净化（Phase 0 必做）

拿到外部素材时，先做一次"去广告"：

1. 删除：机构名、课程广告、价格、优惠、"后台回复领取"、二维码、报名入口链接
2. 删除：他人观点/评价（无法核实）
3. 保留：数字、时间、条件、规则、官方原文表述
4. 若整页都是广告（如课程海报），**整页丢弃**，不要试图改写

> 净化结果记入 `raw_text.md` 顶部："已剔除：机构名 3 处、二维码 1 处、课程推广 2 段"。
