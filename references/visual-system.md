# 视觉系统与出图数据结构

## 一、画布规范

| 项 | 值 |
|---|---|
| 尺寸 | 1080 × 1440（3:4，小红书竖版） |
| 安全边距 | 左右 80，上 90，下 120 |
| 底部呼吸区 | 最后一行文字距底 ≥ 200 |
| 输出 | PNG，RGB（不用 RGBA 直接存） |
| 张数 | 封面 1 + 内容 3-7 + 结尾 1，总计 5-9 张 |

## 二、字体层级

| 用途 | 字号 | 字重 |
|---|---|---|
| 封面主标题 | 100 / 88（两行时递减） | Bold |
| 封面副标题 | 40 | Regular |
| 内容页标题 | 62 | Bold |
| 小标题 / 编号 | 34 | Bold |
| 正文条目 | 42 | Regular |
| 强调条 | 40 | Bold |
| 注释 / 脚注 | 27 | Regular |
| 页码 | 24 | Regular |

字体回退链：`msyhbd.ttc`（标题）→ `simhei.ttf`；`msyh.ttc`（正文）→ `simhei.ttf`。

```json
    },
    {"type": "quote", "text": "岗位少但城市吸引力强，竞争比自然高。", "from": "选岗提示"},
    {
      "type": "ending",
      "index": "06",
      "heading": "三个动作",
      "bullets": ["先筛专业", "再看限制条件", "最后比竞争比"],
      "cta": "理性选岗，比追热门更重要"
    }
  ]

```

字段约束：
- `title_lines`：1-3 行，每行 ≤8 字（超出会缩字号）
- `bullets`：每页 3-6 条，每条 ≤26 字（超出自动换行，最多 2 行）
- `data.rows`：≤10 行；超过请拆成两页
- `cta`：**禁止**任何引流话术（不放"评论区""主页""领取"）
- 所有文本禁止 emoji（PIL 渲染会出豆腐块）

## 四、6 种版式

### 1. magazine 杂志刊头
- 顶部：细横线 + `kicker` + 右侧期号风格小字
- 大标题左对齐，一行一个色块强调关键词
- 内容页：左侧竖排大编号（`index`），右侧正文
- 色块与细线是唯一装饰，禁止渐变

### 2. card 卡片流
- `surface` 色圆角卡片（圆角 24），内边距 48
- 每张卡片一个信息块，卡片间距 32
- 标题在卡片外，正文在卡片内
- 适合"清单体""问题-解答"

### 3. bigtype 大字报
- 标题占上半屏，字号 120+
- 正文只留 3-4 条，字号 48，行距 1.6
- 大量留白，强调"一句话打透"
- 适合"结论前置""犀利提醒"

### 4. memo 手账便签
- 背景铺 40px 网格线（`line` 色，透明度低）
- 左上角画一条 45° 色带（宽 160，高 34，accent 色）模拟胶带
- 正文用手写感排版：行距大、首行缩进、圆点用实心小方块
- 适合"备考者自述""过来人复盘"

### 5. data 数据页
- 顶部标题 + 右侧单位说明
- 表格：隔行浅底，数字列右对齐并加粗，第一列左对齐
- 数值最大项用 `accent` 标记（左侧竖条 6px）
- 底部注释必须写口径

### 6. index 目录索引
- 封面即目录：编号 01-06 + 条目标题 + 右侧细虚线
- 内容页右上角带 `index` 页码
- 适合干货多的素材，天然降低"重复感"

## 五、配色使用

读 `assets/palettes.json`，按 `variant.palette` 取：

| 角色 | 用法 |
|---|---|
| `bg` | 整页背景 |
| `surface` | 卡片底 / 表格隔行底 |
| `ink` | 主文字、标题 |
| `sub` | 注释、副标题、页码 |
| `accent` | 关键词、数字、强调条（**每页 ≤3 处**） |
| `accent2` | 次级强调、图表第二色 |
| `line` | 分割线、网格、虚线 |

深浅模式决定 logo 版本：`mode=light` → `offcn_dark.png`；`mode=dark` → `offcn_light.png`。

## 六、logo 与小鹿落位

**logo（强制）**
- 位置：左下，x=80，y=1440-120（底边对齐呼吸区）
- 高 44px，宽按比例（不拉伸）
- 不透明，不加底衬（浅底用深色版已够清晰）

**小鹿（可选）**
- 位置：右下，右边缘距边 60，底部与 logo 同一基线
- 高度 200-260px（封面可 280）
- 只放封面和结尾页，中间内容页不放（避免干扰阅读）
- 不得压住文字：绘制前预留右下 300×300 区域，正文避让
- 透明底 PNG 直接 `alpha_composite`

---

## 七、渲染层铁律（改代码时别破坏）

1. **不画二维码**——代码里不存在该能力
2. **logo 每张必画**，位置固定，不因版式变化
3. **图片内禁 emoji**，用 `·` `—` `▍` `▶` 等几何符号
4. **RGBA 陷阱**：带 alpha 的 fill 直接画在 RGBA 画布上会覆盖而非混合，半透明元素必须先画到独立图层再 `alpha_composite`
5. **溢出静默**：PIL 不会报错，只会裁掉。每段文字绘制前用 `textbbox` 实测高度，超出就缩字号或换行
6. **行高**：正文行高 = 字号 × 1.55，标题行高 = 字号 × 1.25
7. **末行检查**：最后一条文字底部 + 40 ≤ 画布高 - 120

## 八、出图后自检（逐张看图）

| # | 检查项 | 不合格表现 |
|---|---|---|
| 1 | 文字重叠 | 小标签压住大数字、编号压住标题 |
| 2 | 末行被裁 | 表格最后一行缺失、条目底部贴边 |
| 3 | 白字白底 | 深色模式文字画在浅色卡片上 |
| 4 | 豆腐块 | 出现 □□□ 方框（emoji 或字体缺字） |
| 5 | logo 缺失/糊 | 底部空白或 logo 被小鹿压住 |
| 6 | 留白不一致 | 各张底部空白差异明显 |
| 7 | 配色冲突 | 同一套图里出现色板外的颜色 |
| 8 | 小鹿压字 | 插画盖住正文 |

任一不过 → 改 `content.json` 重渲，禁止带病交付。
